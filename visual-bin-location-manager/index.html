📖 Hướng Dẫn Nạp File Excel Có Ảnh

Hỗ trợ nạp hàng trăm đến hàng ngàn vị trí bao bì / nguyên liệu từ file Excel (.xlsx) có ảnh chèn trong 1-Click!

PHẦN 1: Hướng Dẫn Upload File Excel Siêu Tốc

1
Bấm nút "📥 Tải Mẫu Excel" để lấy file mẫu chuẩn

File có sẵn các cột: Mã Vị Trí, Tên Hàng Hóa, Kho, Dãy/Kệ, Tầng/Ô, Tồn Kho, Ghi Chú.

2
Điền dữ liệu & Chèn hình ảnh trực tiếp vào dòng Excel

Chèn ảnh vào cell hoặc dán đường dẫn ảnh vào cột "Link Ảnh Hoặc Base64".

3
Bấm nút "📊 UPLOAD FILE EXCEL (.XLSX)" để nạp

Hệ thống tự bóc tách dữ liệu & trích xuất ảnh trong vòng 1 giây!

4
Bấm "💾 Backup" để xuất file sao lưu vị trí + ảnh (.json)

Dữ liệu lưu vĩnh viễn trong LocalStorage. Backup để phòng xa!

⚠️ Lưu Ý Quan Trọng Về Bảo Vệ Dữ Liệu

  • Dữ liệu được lưu vĩnh viễn trong LocalStorage của trình duyệt này.
  • Backup thường xuyên bằng nút "💾 Backup JSON" để có bản dự phòng.
  • Chức năng "Xóa Trắng" yêu cầu nhập PIN bảo vệ chống xóa nhầm.
  • Mỗi ảnh tự động nén xuống ~30KB để lưu 3.000+ hình không bị lag.
