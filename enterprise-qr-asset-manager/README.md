# 🏢 Enterprise Fixed Asset & Label Printer QR Manager

Hệ thống quản lý **Tài sản cố định Doanh nghiệp & Máy in tem nhãn QR Code** giao diện **Trắng Sáng (Clean Light Theme)** chuyên nghiệp, tối ưu hoàn hảo cho các dòng máy in nhãn nhiệt/decal (*Xprinter, TSC, Zebra, Brother, Godex...*).

---

## ✨ Features (Tính năng cốt lõi Doanh nghiệp)

1. **☀️ Giao diện Trắng Sáng (Light Minimalist Theme)**:
   - Màu sắc nhã nhặn, tương phản cao, chuẩn văn phòng & nhà máy.
   - Thống kê Tổng số tài sản, Tổng nguyên giá (Tỷ VNĐ), Thiết bị dự phòng, Thiết bị đang bảo trì.

2. **🖨️ Label Printer Studio (In Tem Nhiệt Nhiểu Khổ Tem)**:
   - Hỗ trợ căn chỉnh lề chuẩn mm cho các khổ tem phổ biến: **50x30mm**, **70x40mm**, **100x50mm**.
   - Tem nhãn chuẩn gồm: Mã QR đen trắng vector + Mã tài sản (`AST-2026-XXXX`) + Tên thiết bị + Số Serial + Tên Phòng ban.

3. **🏢 Quản lý Tài sản Quy mô Doanh nghiệp**:
   - Phân cấp theo phòng ban: *Khối Văn Phòng, Khối IT, Nhà Máy Sản Xuất, Kho Thiết Bị*.
   - Theo dõi 5 trạng thái: `Đang sử dụng`, `Dự phòng trong kho`, `Luân chuyển/Cho mượn`, `Đang bảo trì/Sửa`, `Đã thanh lý`.

4. **📊 Xuất File Excel (CSV) & Nhật Ký Bảo Trì**.

---

## 🚀 Quick Start (Chạy ứng dụng)

```bash
cd enterprise-qr-asset-manager
python -m http.server 8096
```
Truy cập trình duyệt: `http://localhost:8096/index.html`
