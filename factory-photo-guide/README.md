## ✨ Tính Năng Chính

### 🗺️ Bản Đồ Ảnh Địa Điểm
- Duyệt tất cả địa điểm trong nhà máy dạng lưới ảnh
- Lọc theo Khu Vực / Tòa Nhà / Loại / Tầng
- Tìm kiếm nhanh bằng tên phân xưởng
- Chụp & lưu ảnh thực tế từ điện thoại

### 🧭 Hướng Dẫn Đường Đi Từng Bước
- Chọn **điểm xuất phát** và **điểm đến** linh hoạt
- Xem hướng dẫn từng bước với ảnh thực tế
- Thanh tiến trình hiển thị vị trí trong lộ trình
- Công nhân / Khách bấm `→ Bước Tiếp` từng bước như Google Maps

### 📱 QR Code Dán Tường
- Tạo QR code cho **từng địa điểm** một nút bấm
- **In từng QR** (khổ sticker, có thông tin địa điểm)
- **In tất cả QR** (A4, nhiều địa điểm / tờ)
- Quét QR → mở thẳng trang thông tin địa điểm đó!

### 📊 Nạp Hàng Loạt Từ Excel
- Upload file `.xlsx` → tự động bóc tách địa điểm + ảnh đính kèm
- Tải mẫu Excel chuẩn để điền nhanh
- Backup / Restore dữ liệu JSON
